# Локальная инверсия отказной компоненты по глубине

Статус: исследовательское предложение, код не изменён.

После написания предложения механика была отдельно проверена в
[STATIC_MECHANICS_AUDIT.md](STATIC_MECHANICS_AUDIT.md). Для первой реализации
там выбран более устойчивый частный случай: центральное плато
`inner_radius`, внешний радиус `outer_radius` и фиксированный cubic smoothstep
на краях. Это сохраняет идею Bézier-хэндлов, но не добавляет плохо
идентифицируемый `edge_power` в первый поиск.

## 1. Исправленная постановка

Нужная величина — не поправка к уже существующей кривой Heretic.
Предполагается, что в динамике отказа по глубине есть ограниченная зона, где
отказная компонента возникает или резко усиливается. Интервенция должна:

1. быть нулевой вне этой зоны;
2. плавно включаться на левом краю;
3. в центре удалить или инвертировать отказную компоненту;
4. плавно выключаться на правом краю;
5. не менять остальные слои.

Схематично:

```text
сила отказного сигнала
                   ╭────╮
база ──────────────╯    ╰──────────────

вес интервенции λ
                   ╭────╮
0 ─────────────────╯    ╰────────────── 0
                  зона вмешательства
```

Это не утверждает, что реально существует один такой всплеск. Его наличие,
центр и ширину надо доказать причинным тестом.

## 2. Что означает «инвертировать»

Без нормировки строк базовая операция Heretic имеет вид

```text
W' = W - λ v (vᵀW)
   = (I - λvvᵀ) W,
```

где `v` — единичное направление отказа.

Для компоненты матрицы вдоль `v`:

| λ | результат |
|---:|---|
| 0 | веса не меняются |
| 0 < λ < 1 | компонента ослабляется |
| 1 | компонента удаляется |
| 1 < λ < 2 | компонента появляется с противоположным знаком, но слабее |
| 2 | знак меняется при сохранении модуля |
| λ > 2 | инвертированная компонента усиливается |

Поэтому формулировка «локальная инверсия» математически точна для `λ ≈ 2`.
Однако противоположный знак компоненты не гарантирует «положительный ответ»:
это поведенческая гипотеза, которую надо проверять генерацией.

Есть два важных ограничения:

- плотный путь с `row_normalization = FULL` после rank-1 операции снова
  нормирует строки и аппроксимирует дельту SVD ранга 3
  (`src/heretic/model.py:589-642`), поэтому там `λ=2` уже не является точной
  алгебраической инверсией;
- текущий путь слитых экспертов применяет голую проекцию
  (`src/heretic/model.py:712-733`), и там интерпретация `λ` ближе к точной.

Следовательно, одинаковое значение амплитуды нельзя заранее считать одинаковой
силой воздействия для плотных модулей и слитых экспертов.

## 3. Почему нынешняя кривая плохо описывает гипотезу

Текущий профиль задаётся четырьмя числами:

```text
max_weight
max_weight_position
min_weight
min_weight_distance
```

Внутри радиуса используется линейная «палатка», за радиусом вес сразу становится
нулём (`src/heretic/model.py:520-530` и `src/heretic/model.py:712-717`).

Если `min_weight > 0`, на границе возникает скачок от положительного значения
прямо к нулю. Положение пика и радиус одновременно перемещают:

- максимум;
- левую границу;
- правую границу;
- веса почти на всех затронутых слоях.

Поэтому один параметр нельзя интерпретировать как найденный «слой ошибки».

## 4. Рекомендуемый профиль: компактное гладкое окно

Пусть слой нормализован в `x ∈ [0, 1]`. Определим:

```text
c   — центр предполагаемой отказной зоны;
rL  — радиус влево;
rR  — радиус вправо;
A   — амплитуда λ в центре;
pL  — форма левого края;
pR  — форма правого края.
```

Для плавного перехода удобно использовать степенной logit-smoothstep:

```text
S_p(t) = t^p / (t^p + (1 - t)^p),  0 ≤ t ≤ 1.
```

В логарифмической форме это:

```text
logit(S_p(t)) = p · logit(t).
```

Это даёт понятную связь с предложенной «логарифмической кривой относительно
опорной точки»:

- `p = 1` — линейный край;
- `p > 1` — плавный S-образный край с нулевым наклоном;
- большой `p` — более резкая граница;
- `pL` и `pR` работают как независимые Bézier-хэндлы.

Компактное окно:

```text
B(x) = 0,                                      x ≤ c-rL
B(x) = S_pL((x-(c-rL))/rL),                   c-rL < x ≤ c
B(x) = S_pR(((c+rR)-x)/rR),                   c < x < c+rR
B(x) = 0,                                      x ≥ c+rR

λ(x) = A · B(x).
```

Свойства:

- строго нулевой вес вне окна;
- `λ(c) = A`;
- края непрерывны;
- при `pL,pR > 1` наклон на границах и в центре стремится к нулю;
- нет отрицательных весов и Bézier-петель;
- вычисление не требует обращения `x(t)`.

## 5. Минимальная версия для первого теста

Свободные Bézier-хэндлы для каждого компонента слишком быстро раздуют поиск.
Первая версия должна иметь только:

```text
center
radius
amplitude
edge_power
```

То есть `rL = rR` и `pL = pR`. Только после доказанного выигрыша добавлять
асимметрию.

Рекомендуемые исходные диапазоны как предмет обсуждения, а не готовые константы:

```text
center:       любой слой, но после диагностического скана — только найденный интервал
radius:       1..L/3 слоёв, логарифмическое семплирование
amplitude:    0..2.5
edge_power:   1..6
```

`radius` лучше искать в логарифмической шкале: разница между 1 и 2 слоями
существеннее разницы между 15 и 16.

## 6. Вариант с плато

Журнал Qwen показывает, что текущий поиск любит профиль, похожий на шторку:
длинное плато и резкое выключение. Поэтому гладкий одиночный пик нельзя делать
единственной новой формой.

Альтернативный профиль:

```text
0 → плавный вход → плато A → плавный выход → 0
```

Параметры:

```text
center
radius
plateau_fraction
amplitude
edge_power
```

Необходимо честное сравнение:

1. старая линейная палатка;
2. гладкий компактный пик;
3. гладкая шторка с плато.

Вполне возможно, что резкая граница функциональна, а не является дефектом
параметризации.

После статической проверки именно этот вариант рекомендуется как первый:

```text
center
inner_radius
outer_radius
amplitude
S(t) = 3t^2 - 2t^3
```

Он теми же четырьмя свободными числами различает положение зоны, ширину
центральной инверсии и радиус плавного влияния. Одиночный bump получается как
`inner_radius=0`, поэтому отдельное семейство для него не требуется.

## 7. Один профиль или несколько

Нельзя сразу дать каждому из четырёх компонентов Qwen полностью независимые
`c, rL, rR, A, pL, pR`: это добавит до 24 параметров и ухудшит идентифицируемость.

Рекомендуемый порядок:

1. диагностически найти полезные окна отдельно для каждого компонента;
2. отключить компоненты без воспроизводимого причинного эффекта;
3. для оставшихся искать минимальный симметричный профиль;
4. добавить асимметрию только там, где левый и правый края явно ведут себя
   различно;
5. второй пик разрешать только после измеренной неаддитивности двух зон.

По старому журналу уже видно, что attention и MLP используют разные границы,
поэтому один общий профиль на них накладывать нельзя. Общую позицию можно
использовать только как проверяемое сокращение пространства.

## 8. Что означает «не корёжить весь слой»

Нынешняя операция не переписывает матрицу произвольным образом: это направленная
rank-1 дельта `-λv(vᵀW)`. При `FULL` она превращается в низкоранговую
норм-сохраняющую аппроксимацию. Поэтому есть две независимые локальности:

1. **по глубине** — какие слои получают ненулевой `λ`;
2. **в пространстве признаков** — какое направление или подпространство
   удаляется внутри выбранного слоя.

Предлагаемое окно решает первую задачу. Если вред качеству остаётся внутри
правильного окна, следующий шаг — не ещё сильнее сужать радиус, а проверять
направление: несколько направлений, ковариационно корректный проектор,
SAE-признаки или экспертную селективность.

Покоординатная разреженность самого `v` нежелательна: координаты residual stream
зависят от выбора базиса и не имеют устойчивой интерпретации.

## 9. Критерий успеха

Новый профиль считается полезным, только если при одинаковом бюджете:

- улучшает семантическую долю `REFUSAL` на замороженном наборе;
- не ухудшает perplexity относительно сопоставимой старой точки;
- не увеличивает ложные отказы на harmless/tech-sensitive контроле;
- центр и радиус воспроизводятся на разбиениях промптов и нескольких seeds;
- преимущество сохраняется при ручной или модельной смысловой проверке ответов,
  а не только по словам-маркерам.
